Selected work

Exhibit A

The export the consultants called non‑automatable.

On an Oracle Fusion Cloud implementation, the integration consultants assessed Enterprise Data Management extracts as a permanently manual workflow. I read the API documentation differently. The result is a scheduled OAuth 2.0 client against EDM’s REST interface that authenticates, extracts, and stages dimension data without a human in the loop — retiring both the labor and the keying errors that traveled with it.

Oracle EDM · REST · OAuth 2.0

✓ manual workflow retired

Exhibit B

Extract tooling that refuses to corrupt identifiers.

Spreadsheets coerce data types silently: a legacy ERP identifier opened in Excel can shed its leading zeros or collapse into scientific notation, and nobody notices until a reconciliation fails weeks later. I built a PowerShell library that automates BigQuery extracts with integrity safeguards engineered around exactly that failure — types preserved end to end, by default, on every run.

PowerShell · BigQuery · bq CLI

Models a data science institute carried into production.

SQL and data models I built for implementation reporting were adopted by the health system’s internal data science institute into its production analytics products. There is no stronger code review than another team choosing to run your work.

About

I came up through healthcare finance — general ledger oversight for roughly 1,600 business units through a twenty-billion-dollar annual close. That vantage teaches you precisely what happens downstream when data is wrong, and it is why I moved deliberately toward the engineering side of the problem: when the data layer is sound, everything built on top of it gets easier.

Alongside the day job, I have spent a decade in nonprofit governance — treasurer and director roles for education and public-health organizations, drafting bylaws, financial policy, and audit-ready reporting. Governance work and data work turn out to be the same discipline at different altitudes: controls, accountability, and documentation people can rely on.

Away from the keyboard, I write long-form fiction and make independent film.

The bottom line

I am interested in analytics engineering and senior data roles where trustworthy data is treated as the product — particularly in healthcare. If that is what you are building, I would like to hear about it.
